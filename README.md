# My Personal Portfolio

A simple multi-page personal portfolio website built with HTML5 and CSS3
for **CS313: Web Engineering (Lab 3 - HTML Advanced)**.

## Pages
- `index.html` – Home / introduction
- `hobbies.html` – Hobbies
- `skills.html` – Personal & technical skills
- `gallery.html` – Image gallery (float-based layout)
- `contact.html` – Contact details

## Folder Structure
```
portfolio/
├── index.html
├── hobbies.html
├── contact.html
├── gallery.html
├── skills.html
├── css/
│   └── style.css
├── images/
│   ├── photo1.jpg
│   ├── photo2.jpg
│   └── ...
└── README.md
```

## Features
- All styling moved to an external stylesheet (`css/style.css`)
- Horizontal navigation menu styled with CSS
- `float` and `clear` used to arrange the profile section and image gallery
- No JavaScript or CSS frameworks used
